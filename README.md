# E-Commerce Website

A responsive frontend e-commerce website built using HTML, CSS, and JavaScript. The project provides a simple shopping interface with product categories, navigation, and interactive elements.

## 🚀 Live Demo

https://adaridatta9090.github.io/ecommerce-website/

## ✨ Features

- Responsive e-commerce website design
- Product browsing interface
- Category-based product organization
- Navigation between website sections
- Interactive JavaScript elements
- Product images organized by category
- Clean HTML and CSS structure

## 📄 Pages / Sections

- Home
- Accessories
- Clothes
- Footwear
- Product sections
- Shopping cart interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
